Nothing in the source is approved by default (CLAUDE.md §9). In the source, every one of the 238 recommended answers is pink "proposed decision" text; none records confirmed direction on its own.

## Status rules

Statuses were assigned mechanically by these rules, so they can be re-run and challenged:

| Status | Rule |
|---|---|
| **Confirmed** | Adopted as a standing instruction in CLAUDE.md, or settled in [decisions.md](decisions.md). |
| **Deferred** | A class CLAUDE.md §7 defers (confined space, complex lifting/rigging, excavation/penetration, rare specialist) or the finance workflow (Q228). |
| **Requires specialist validation** | Q236 assigns the question to a technical authority / Approved Person, an insurer or a privacy adviser. |
| **Proposed** | Everything else: founder, contractor or gate/security input, decidable without specialist sign-off. |
| **Implemented** | None yet. Only set once implemented *and* tested. |

**Reviewer** is the Q236 proposed workshop allocation, not exclusive ownership.
**Summary** is the first sentence of the recommended answer; read the source for conditions and risks.
**Notes** flags rows that are venue configuration with no silent default (CLAUDE.md §9), rows whose answer depends on earlier Olympia/OES context and must be checked against controlled source (Q234), and rows that cite your earlier direction (candidates for Confirmed once you say so).
